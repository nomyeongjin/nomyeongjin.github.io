2024.05 - 2024.06

6인 팀 프로젝트

FOODPIN은 음식점 예약 서비스를 제공하는 사이트로 사용자 위치 기반으로 근처 맛집 정보를 제공합니다.

사용자 위치 데이터를 활용해 주변 음식점 정보를 추천하고, 검색 및 예약 프로세스를 통합 제공하는 서비스입니다. UX/UI를 고려한 HTML5/CSS3 기반의 인터페이스를 구축하고, Java 백엔드 로직을 통해 실시간 위치 탐색 및 안정적인 예약 관리 시스템을 구현했습니다.

- SMS API 연동을 통한 휴대폰 본인 인증 및 번호 대조 검증 로직 구현

- BCrypt 단방향 암호화 알고리즘을 적용한 사용자 비밀번호 데이터 보안 강화

- 회원 및 가게 정보 DB 등록 전 클라이언트/서버 양방향 유효성 검사(Validation) 처리

- 사용자 유형(일반 회원/가게 회원)별 분기 처리를 통한 다원화된 회원가입 프로세스 구축

- Cookie 기반의 아이디 저장 기능 및 사용자 편의 중심의 로그인/페이지 이동 로직 구현

- 본인 인증 연동을 통한 사용자 아이디 목록 조회 및 안전한 비밀번호 재설정 기능 구현

- WebSocket(또는 Stomp) 기반의 가게-사용자 간 1:1 실시간 기술 문의 및 채팅 서비스 구축

- 이전 대화 기록(Chat History) 데이터 조회 및 동적 렌더링 처리

- 채팅방 목록 키워드 검색 및 사이드바 연동을 통한 관리자 문의 창구 구현

- 실시간 메시지 수신 시 헤더 뱃지(Badge) 알림 표시 및 읽음 상태 변경 처리

직관적이고 안정적인 사용자 경험(UX/UI)을 위해 HTML5/CSS3 기반의 화면을 설계하고, Java 백엔드 로직을 통해 데이터 관리의 신뢰성을 확보했습니다.

- 네이버 스마트 에디터 API 연동을 통한 사용자 맞춤형 게시글 작성 및 수정 환경 구축

- 게시글 썸네일 및 첨부 이미지의 동적 삽입, 수정, 삭제 처리 로직 구현

- JavaScript를 활용한 작성 폼 및 입양 문의 폼의 입력 데이터 유효성 검증(Validation) 수행

- SQL 기반의 조건별(카테고리, 키워드) 게시글 검색 및 페이징(Pagination) 처리

- DB의 상태 값을 변경하여 데이터를 보존하는 논리 삭제(Soft Delete) 방식의 게시글 삭제 로직 구현

- 북마크(관심 게시글 등록) 기능 구현을 통한 회원 맞춤형 데이터 제공

- Google SMTP 및 Java Mail API를 활용한 게시글 작성자 대상 1:1 입양 문의 이메일 발송 기능 구현
